# OneWili API Reference

Generated from the FreeWili 2 firmware menu sources by the menutool API Generator.
One reference for every generated language - see the signature blocks on each command.

The packages themselves - Python, C, Rust, WiliBSP, WASM and CM0 - are at [github.com/freewili/onewili](https://github.com/freewili/onewili).

## Guides

Hand-written, covering capabilities that are not menu commands:

- [SD card access from WiliBSP](sd-card.md) - the `ow_sd_*` API for apps on the FreeWili 2 display CPU
- [File transfer hardware smoke test](file-transfer-hardware-smoke.md) - manual checklist for the host file-transfer protocol
